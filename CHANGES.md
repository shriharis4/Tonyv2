## [Build 4] — UI Stylesheet Interpolation KeyError Fix

- **Problem**: Launching `python main.py` crashed during `ModernFloatingWindow.__init__` -> `VoiceEngineWidget.init_ui()` with:
  `KeyError: '\n background'` at `self.noise_bar.setStyleSheet(PROGRESSBAR_STYLESHEET.format(color="#ff007f"))`.
- **Root Cause**: `PROGRESSBAR_STYLESHEET` contained unescaped single braces around CSS properties (`QProgressBar { background: ... }`). Python's `str.format()` treated `{ background: ... }` as an interpolation field name rather than literal CSS braces.
- **Fix in `tony.py`**:
  - Escaped literal braces to `{{` and `}}` in `PROGRESSBAR_STYLESHEET`, leaving `{color}` as the sole template parameter.
  - Verified widget and HUD initialization end-to-end with exit code 0.

## [Build 5] — Audio Pipeline QueueFull Exception Flood Fix

- **Problem**: Launching voice engine flooded the console with hundreds of unhandled asyncio exceptions:
  `ERROR:asyncio:Exception in callback Queue.put_nowait(rtc.AudioFrame(... duration=0.010))`
  `asyncio.queues.QueueFull`.
- **Root Cause**: `livekit.rtc.media_devices.MediaDevices.open_input` runs a low-level audio capture callback via `sounddevice` at 100 Hz in an OS audio thread. The default queue capacity was only 50 frames (500 ms). When the event loop was busy during startup and initial WebRTC negotiation, the queue filled to capacity. The sounddevice thread scheduled `loop.call_soon_threadsafe(q.put_nowait, frame)`, which caused `q.put_nowait` to execute on the full queue and raise `asyncio.QueueFull` inside asyncio's callback runner.
- **Fix in `tony.py` and `livekit.rtc.media_devices`**:
  - In `tony.py`, added a runtime wrapper around `MediaDevices.open_input` that replaces `asyncio.Queue` during capture initialization with a `_SafeQueue` whose `put_nowait()` drops extra frames on overflow rather than raising unhandled exceptions into the event loop.
  - Increased `queue_capacity` from 50 (500 ms) to 500 (5 seconds) in `self.devices.open_input(...)` in `tony.py`.
  - Patched `livekit/rtc/media_devices.py` in `.venv` so `_safe_put()` catches any `Exception` during `put_nowait()`.
  - Tested module loading and patch application: verified exit code 0 with clean patch hook active.
